Global Aerosols — Data Downloads

NASA MERRA-2 extinction aerosol optical thickness at 550 nm (dust, black carbon, organic carbon, sulfate, sea salt) and total precipitable water vapor, every 3 hours (HH:30 UTC), 0.5° × 0.625°, August 2018–January 2020. One NetCDF file per month.

Variables

  • DUEXTTAU — dust extinction AOT (dimensionless)
  • BCEXTTAU, OCEXTTAU — black carbon and organic carbon extinction AOT (summed as smoke / carbon in the animation)
  • SUEXTTAU — sulfate extinction AOT
  • SSEXTTAU — sea salt extinction AOT
  • TQV — total precipitable water vapor (kg m−2)

Each file holds the hourly time-averages centered at 00:30, 03:30, … 21:30 UTC, the same timesteps the animation renders. AOT values are rounded to 4 decimals and water vapor to 0.1 kg m−2.

Directions

  1. Download all 18 files above into one folder.
  2. Download the 2004 monthly Blue Marble Next Generation base maps (world.2004MM.3x5400x2700.jpg, all 12 months) into a second folder.
  3. Open global_aerosols_platecarree.py (or the R version), set DATA_DIR to the first folder and BLUE_MARBLE_DIR to the second, and run it.
DATA_DIR/
    global_aerosols_merra2_3hourly_YYYY-MM.nc   (18 files)
BLUE_MARBLE_DIR/
    world.2004MM.3x5400x2700.jpg               (12 files)
