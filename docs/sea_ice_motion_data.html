Sea Ice Motion — Data Downloads

Daily NOAA/NSIDC G02202 V6 Arctic sea ice concentration (NetCDF) and IABP buoy positions (Parquet), 1979–2022.

Sea Ice Concentration

  • 1979–1989 (888 MB)
  • 1990–1999 (1.0 GB)
  • 2000–2009 (997 MB)
  • 2010–2022 (1.2 GB)
  • Gap-filled days (2.7 MB)

Buoy Positions

  • IABP daily positions, projected (22.9 MB)

Directions

  1. Download all six files above into one folder.
  2. Unzip the four concentration zips into the same folder. They merge into a single sea_ice_concentration/ folder with one subfolder per year.
  3. Unzip sea_ice_concentration_filled.zip in the same folder.
  4. Create an iabp_buoys/ folder and move the parquet file into it.
  5. Open render_sea_ice_motion.py, set DATA_ROOT to that folder, and run it.
DATA_ROOT/
    sea_ice_concentration/<year>/sic_psn25_YYYYMMDD_*.nc
    sea_ice_concentration_filled/<year>/sic_psn25_YYYYMMDD_*.nc
    iabp_buoys/iabp_daily_positions_1979_2022_projected.parquet

Sources
